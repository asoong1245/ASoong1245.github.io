Variables

Variables are containers used to store data in a program. In Python, you do not need to declare the type of a variable because Python automatically determines it.

Variables can store numbers, text, lists, and more. They can also change value during program execution.

x = 5
name = "John"

In this example, x stores a number and name stores text.

Data Types

Data types define what kind of value a variable holds. Python automatically assigns types based on the value.

  • int → whole numbers like 10 or -3
  • float → decimal numbers like 3.14
  • string → text inside quotes
  • boolean → True or False values
  • list → collection of multiple items

Comments

Comments are used to explain code and are ignored by Python when running the program. They help programmers understand what the code is doing.

# This is a comment
x = 5  # This stores a value

Comments are very useful for organizing and documenting code.

Operators & Comparisons

Comparison operators are used to compare two values and return True or False.

  • == → checks if values are equal
  • != → checks if values are not equal
  • > → greater than
  • < → less than
x = 10
print(x == 10)  # True
print(x != 5)   # True

Operator Precedence

Operator precedence determines the order in which operations are performed in an expression. Python follows standard math rules.

Multiplication and division happen before addition and subtraction unless parentheses are used.

result = 2 + 2 * 2
# multiplication happens first → 2 * 2 = 4 → 2 + 4 = 6

You can use parentheses to change the order.

Built-in Functions

Built-in functions are pre-written functions provided by Python that you can use without importing anything.

One common function is len(), which returns the number of items in a string or list.

text = "hello"
print(len(text))  # 5

Lists

Lists are used to store multiple values in a single variable. They are ordered and can be changed.

fruits = ["apple", "banana", "cherry"]
print(fruits[0])

You can also add items using append().

Dictionaries

Dictionaries store data in key-value pairs. Each value is accessed using its key instead of a number index.

student = {
    "name": "Alice",
    "age": 20
}

print(student["name"])

Loops

Loops are used to repeat code multiple times.

A for loop repeats a fixed number of times, while a while loop runs as long as a condition is true.

for i in range(5):
    print(i)

x = 0
while x < 5:
    print(x)
    x += 1

Functions

Functions are reusable blocks of code that perform a specific task. They help keep programs organized and avoid repetition.

def greet(name):
    print("Hello " + name)

greet("John")

Conditionals

Conditionals allow programs to make decisions based on conditions.

If the condition is True, the code runs. Otherwise, it moves to the next option.

x = 10

if x > 5:
    print("Greater than 5")
else:
    print("5 or less")

Input & Output

Input allows the user to enter data into the program. Output displays results.

name = input("Enter your name: ")
print("Hello " + name)

Variable Naming Rules

Variable names must follow rules to be valid in Python:

  • Must start with a letter or underscore
  • No spaces allowed
  • No special symbols like - or !
  • Case-sensitive (myVar ≠ myvar)

Error Handling

Error handling allows programs to continue running even when something goes wrong.

It uses try and except blocks.

try:
    x = 10 / 0
except:
    print("An error occurred")

Modules

Modules are external Python files that provide extra functionality.

You can import built-in modules like math to access advanced functions.

import math
print(math.sqrt(16))

Object-Oriented Programming (OOP)

OOP is a programming style that uses classes and objects to represent real-world things.

A class is a blueprint, and an object is an instance of that blueprint.

class Dog:
    def __init__(self, name):
        self.name = name

dog1 = Dog("Buddy")
